=====================================================================
 PREPARAR EL ENTORNO DE LA DEMO · TEL354 G01 · R1 y R2 en Mininet
=====================================================================
 Orden: VirtualBox -> Ventana 1 (ONOS) -> Ventana 2 (Mininet) -> Ventana 3 (Menu)
 No saltes pasos: cada ventana necesita que la anterior ya este lista.


---------------------------------------------------------------------
 PASO 0 · VIRTUALBOX
---------------------------------------------------------------------
 1. Abrir VirtualBox -> seleccionar "Mininet-VM"
 2. Flechita al lado de "Iniciar" -> "Inicio sin interfaz"
 3. Esperar ~1 minuto a que arranque


---------------------------------------------------------------------
 PASO 1 · (SOLO SI CAMBIASTE EL MENU) COPIAR EL ZIP DESDE WINDOWS
---------------------------------------------------------------------
 En PowerShell / CMD de Windows:

cd %USERPROFILE%\Downloads
scp tel354-demo-menu.zip mininet@192.168.56.101:/home/mininet/tel354-demo-menu.zip

 (si Windows lo guardo como tel354-demo-menu_1.zip, pon ese nombre a la
  izquierda; el de la derecha se queda igual)
 Clave: mininet


---------------------------------------------------------------------
 VENTANA 1 · ONOS   (PuTTY -> mininet-vm -> Open · usuario mininet / mininet)
---------------------------------------------------------------------
sudo -i
ip link set eth1 up
dhclient eth1
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
export ONOS_APPS=drivers,openflow
/opt/onos/bin/onos-service start

 Esperar 1-2 minutos hasta que salga  onos>  y entonces:

apps -s -a
cfg set org.onosproject.provider.host.impl.HostLocationProvider requestInterceptsEnabled false

 Esperado: 6 apps (drivers, optical-model, hostprovider, lldpprovider,
           openflow-base, openflow) y SIN fwd.
 Si sale "Service ... not found" o "Command not found": esperar y repetir.

 !! NUNCA escribir logout ni Ctrl+D en esta ventana (apaga ONOS y borra las reglas).


---------------------------------------------------------------------
 VENTANA 2 · MININET   (clic derecho en la barra de PuTTY -> Duplicate Session)
---------------------------------------------------------------------
sudo -i
export PYTHONIOENCODING=utf-8 LANG=C.UTF-8
mn -c
cd /home/mininet/tel354-demo
python3 topo/campus_topo_demo.py --services --manual

 Esperado: tabla "Plan de la demo" (h1..h4), 6 servicios en OK y el prompt  mininet>
 Dejar esta ventana asi, con mininet> (no escribir exit).

 Comprobacion en la VENTANA 1 (onos>):

devices

 Esperado: 4 switches con available=true (...0001, ...0002, ...0100, ...0200)


---------------------------------------------------------------------
 VENTANA 3 · MENU   (otra Duplicate Session)
---------------------------------------------------------------------
sudo -i
export PYTHONIOENCODING=utf-8 LANG=C.UTF-8
cd /home/mininet
unzip -o tel354-demo-menu.zip
cd tel354-demo
python3 demo.py

 (el unzip solo hace falta si copiaste un zip nuevo en el PASO 1)

 Primera opcion SIEMPRE: 12 (instalar reglas proactivas)
 Esperado: core: 29 reglas · as1 y as2: 28 reglas · meters: 5


---------------------------------------------------------------------
 TIPS ANTES DE GRABAR
---------------------------------------------------------------------
 - PuTTY en UTF-8 en las 3 ventanas (para que salgan bien las tildes):
   clic derecho en la barra -> Change Settings -> Window -> Translation -> UTF-8 -> Apply
 - Si ves "Error: no alcanzo PostgreSQL" en el menu -> te falto la opcion 12.
 - Si reiniciaste ONOS -> repetir opcion 12 y volver a hacer los logins.


---------------------------------------------------------------------
 APAGAR TODO (cuando termines)
---------------------------------------------------------------------
 VENTANA 3:   0   (salir del menu)

 VENTANA 2:
svc bash /home/mininet/tel354-demo/resources/stop_services.sh
exit
mn -c

 VENTANA 1 (onos>):
logout

 Apagar la VM (en cualquier ventana, como root):
poweroff
